# Дзен: как публиковать серию

_Составлено 11.08.2026. Публикует владелец вручную – у Дзена нет API для статей._

## Что решено

- **Канал личный:** «Максим Подольский, юрист». Не бренд-канал: сравнение
  конкурентов от участника рынка читается как реклама и занижается лентой.
- **Конкуренты называются поимённо**, с ценами и датой замера.
- **Задача канала – не ссылочный вес.** Дзен его не даёт. Задачи: занять выдачу
  Яндекса рядом с vlip и 1ps, охват из ленты, переиспользование текстов
  в рассылке и Телеграме.

## Настройка канала (один раз)

1. Яндекс-аккаунт – тот же, под которым Метрика, Директ и Вебмастер
   (`handoff/ACCESS.md`, п. 7).
2. Название: **Максим Подольский**. Подзаголовок: «Юрист. Персональные данные,
   152-ФЗ, проверки Роскомнадзора».
3. Описание канала:
   > Разбираю, за что Роскомнадзор штрафует сайты. Проверяю чужие сайты
   > и показываю находки на цифрах. Делаю сервис проверки lawchek.ru.
4. Ссылка на lawchek.ru в профиле.
5. Аватар – портрет, не логотип. Личный канал.

## Как опубликовать (интерфейс Дзена)

Кнопки «Опубликовать» в нашем репозитории нет и быть не может – публикация
руками в Студии Дзена. Путь:

1. Зайти на **dzen.ru** под нужным Яндекс-аккаунтом. Вход для авторов
   анонимному посетителю не показывается – сначала логин.
2. Аватар в правом верхнем углу → **Студия**.
3. В правом верхнем углу Студии → **Написать статью**.
4. Поле **Заголовок** (лимит платформы 140 знаков), поле **Текст** – туда
   вставляется тело статьи. Ссылки, картинки и эмбеды вставляются прямо в текст,
   всего вложений не больше 100.
5. Обложка загружается в карточке публикации.
6. **Опубликовать** в правом верхнем углу. Либо **Опубликовать позже** –
   выбрать дату.

Статусы в разделе **Публикации**: Черновик · Ожидает публикации · Опубликовано ·
В обработке · Есть неопубликованные правки · Заблокировано.

> **Отложенная публикация закрывает всё расписание за один вечер.** Заряжаешь
> восемь статей с датами через «Опубликовать позже» и дальше только отвечаешь
> в комментариях. Возвращаться в Студию каждый вторник не нужно.

## Обложки

Готовы, лежат в `docs/dzen/covers/`. 1280×720 при плотности ×2 (то есть
2560×1440 – Дзен сожмёт сам, запас по резкости нужен).

| Статья | Файл |
|---|---|
| №1 | `01-385-saitov.png` |
| №2 | `02-shest-servisov.png` |
| №3 | `03-otkuda-milliony.png` |
| №4 | `04-platnye-tarify.png` |
| №5 | `05-slepye-zony.png` |

Собраны вёрсткой, не генератором картинок: цвета взяты из `base.html`
(navy `#00053d`, brand `#0b5cff`, critical `#991b1b`), поэтому лента и сайт
выглядят одним хозяйством. Пересобрать после правки текста:

```bash
.venv/bin/python docs/dzen/covers/build_covers.py
```

Правила, по которым они сделаны: крупная цифра из заголовка занимает пол-обложки
(в ленте на телефоне карточка мелкая, читается только число), подпись в две
строки, домен в углу.

## Аватар

`covers/avatar.png`, 400×400. Это портрет, который уже стоит на сайте
(`static/lawyer-podolskiy.jpg`, он же og:image), обрезанный под квадрат:
лицо крупно, с запасом сверху, чтобы круглый кроп Дзена ничего не срезал.

Пересобрать с другим кадрированием – масштаб и сдвиг подбираются аргументами:

```bash
.venv/bin/python docs/dzen/covers/build_avatar.py 1.85 -160 -104
```

Одно лицо на сайте, в Дзене и в соцсетях – это узнаваемость. Разные аватары
на разных площадках её ломают.

## UTM

Разметка уже проставлена в текстах. Схема:

```
https://lawchek.ru/?utm_source=dzen&utm_medium=article&utm_campaign=<slug>
```

| Статья | campaign |
|---|---|
| №1 | `385-saitov` |
| №2 | `shest-servisov` |
| №3 | `otkuda-milliony` |

Ссылки внутрь блога размечаются так же – это важнее, чем ссылка на главную:
переход на статью блога даёт поведенческий сигнал именно той странице,
которая борется за позиции.

## Что смотреть в Метрике

Раз в неделю, сегмент «Источник → метка utm_source = dzen»:

- визиты и глубина просмотра;
- доля визитов, дошедших до запуска скана;
- переходы на `/pricing`.

**Чем не мерить:** выручкой в первые месяцы. Дзен работает на верх воронки,
а узкое место сейчас в середине – переход с отчёта на `/pricing` даёт 18%.
Рост трафика сверху это не чинит.

## Правила, чтобы не навредить SEO

1. **Один текст не публикуется дважды.** Дзен трастовее lawchek.ru и в выдаче
   встанет выше собственной страницы блога.
2. **Заголовок №2 не переписывать** под «бесплатная проверка сайта на 152-ФЗ» –
   этот ключ занят статьёй блога `besplatnaya-proverka-sajta-na-152-fz`,
   столкнём две свои страницы.
3. **Каждая статья Дзена ссылается минимум на одну статью блога** по смежной
   теме. Проставлено.
