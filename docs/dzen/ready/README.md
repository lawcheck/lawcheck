# Готово к вставке

Файлы в этой папке собираются из статей командой:

```bash
.venv/bin/python docs/dzen/build_ready.py
```

Markdown из них убран – редактор Дзена его не понимает и напечатал бы
решётки и квадратные скобки буквально. Заголовки разделов лежат отдельными
строками: в редакторе выделяешь строку и жмёшь «Заголовок» на панели.
Ссылки развёрнуты в «текст — URL», голый URL Дзен подхватывает сам.

## Порядок

1. Завести канал, поставить аватар, название, описание, ссылку.
2. Студия → «Написать статью». Заголовок из первой строки файла, тело – остальное.
3. Разделы выделить как заголовки, обложку загрузить.
4. «Опубликовать позже» → дата из таблицы.
5. Повторить для трёх статей за один заход.

Дальше возвращаться в Студию не нужно – статьи выйдут сами.
