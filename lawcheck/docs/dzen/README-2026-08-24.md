# Публикация в Дзен: комплект от 24.08.2026

Три статьи под правило «в Дзен - сокращённая версия с другим заголовком»
(raw/2026-08-23-seo-monitoring-launch.md). Полные версии остаются в блоге lawchek.ru.

## Что в папке

- `ready/*.txt` - готовые тексты: первая строка = заголовок статьи, дальше тело.
  Тексты выверены, НЕ переписывать (суммы штрафов, статьи КоАП, даты - из статей блога).
- `html/*.html` - тело для вставки в редактор Дзена одним синтетическим paste
  (text/html, Draft.js сам развернёт абзацы и ссылки; рецепт - скилл dzen,
  references/dzen-article-editor.md). Вставлять только в ПУСТОЕ тело.
- `html/*.title` - заголовок для первого contenteditable (execCommand insertText).
- `covers/*.png` - обложки 2560×1440 в цветах сайта (#f4f7ff → #1e293b/#0b5cff).

## Порядок публикации (по ранбуку AGENT-RUNBOOK.md)

1. Студия: https://dzen.ru/profile/editor/id/62c9278bb1551267538bd898
2. Создать публикацию → вставить заголовок → paste тела в пустой редактор.
3. Обложка - файл из `covers/` (в самом верху панели публикации, над названием).
   Если загрузка файла не пойдёт из сессии - попросить Максима, один клик.
4. «Опубликовать позже» с датами ниже. Проверить статус в списке публикаций.
5. Публикации проверять глазами на публичной странице, не верить счётчикам фильтров.
